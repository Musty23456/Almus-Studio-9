- Velocity-sensitive sample mapping using existing DrumSample layers.
- Polyphony limit up to 64 voices.
- Mono and legato mode settings.
- Glide/portamento metadata foundation.
- Sustain-pedal setting foundation.

- 25-note audition keyboard (M48–M72).
